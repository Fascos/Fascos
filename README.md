### 📂 Featured Projects
  
- **Investment Readiness Prediction & Recommendation System for Kenyan Adults** *(Moringa Capstone | Team Project | In Progress)* — Collaborating in a team of six to develop a machine learning solution using Kenya’s 2024 FinAccess Household Survey to predict investment usage, identify factors influencing investment participation, and provide personalized recommendations. The project incorporates explainable AI (SHAP) to interpret model predictions and support data-driven financial decision-making.
- - **Financial Loan Approval Prediction** *(Individual Project)* — Developed an end-to-end machine learning solution using 20,000 loan applications to predict loan approval outcomes. Followed the CRISP-DM framework to perform exploratory data analysis, data preprocessing, and model development. Compared six classification algorithms, used GridSearchCV for hyperparameter tuning, and evaluated models using precision, recall, F1-score, ROC-AUC, and a custom business cost metric. Selected a Support Vector Machine (SVM) model with **93.67% precision** and used permutation feature importance to identify key factors influencing predictions and develop business recommendations.
- **EcoSort Waste Management Assistant** — Contributed to a team-built AI assistant that classifies waste from images or text descriptions and provides recycling instructions grounded in policy documents. Developed the Retrieval-Augmented Generation (RAG) component, working on document retrieval, fine-tuning a FLAN-T5 model, grounding tests, and evaluation of generated instructions. The integrated system combines CNN-based image classification, text classification, and transformer-based text generation.
- **Amazon Customer Reviews Analytics: NLP, Time-Series Forecasting & Neural Networks** *(Individual Project)* — Analyzed 997 Amazon customer reviews using NLP techniques, including text preprocessing, lemmatization, TF-IDF, and n-gram analysis. Applied ARIMA and SARIMA models to explore and forecast monthly customer ratings, and developed and evaluated an MLP neural network to classify ratings from review text. Compared model performance and investigated challenges such as class imbalance and overfitting.
- **House Price Prediction & Tableau Dashboard** — Applied machine learning regression techniques to estimate house prices and explore the factors influencing property values. Complemented the analysis with an interactive Tableau dashboard to visualize housing trends, compare property characteristics, and communicate key insights.
