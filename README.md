### 📂 Featured Projects

**1. Investment Readiness Prediction & Recommendation System for Kenyan Adults**
*Moringa Capstone | Team Project | In Progress*

Collaborating in a team of six to develop a machine learning solution using Kenya's 2024 FinAccess Household Survey. The project aims to predict investment usage, identify factors associated with investment participation, and provide personalized recommendations. It incorporates explainable AI (SHAP) to interpret model predictions and support data-driven financial decision-making.

**2. [Financial Loan Approval Prediction](https://github.com/Fascos/financial-loan-approval)**
*Individual Project*

Developed an end-to-end machine learning solution using 20,000 loan applications. Followed the CRISP-DM framework to conduct EDA, preprocess data, and compare six classification models. Used GridSearchCV for hyperparameter tuning and evaluated models using precision, recall, F1-score, ROC-AUC, and a custom business cost metric. Selected an SVM model that achieved 93.67% precision and used permutation feature importance to identify influential features and develop business recommendations.

**3. [EcoSort Waste Management Assistant](https://github.com/Fascos/AI-Waste-Management-Assistant)**
*Team Project | AI and NLP*

Contributed to a team-built AI assistant that classifies waste from images or text descriptions and provides recycling instructions grounded in policy documents. Developed the Retrieval-Augmented Generation (RAG) component, working on document retrieval, FLAN-T5 fine-tuning, grounding tests, and evaluation of generated instructions.

**4. [Amazon Customer Reviews Analytics: NLP, Time-Series Forecasting & Neural Networks](https://github.com/Fascos/amazon-reviews-analytics)**
*Individual Project*

Analyzed 997 customer reviews using NLP techniques, including text preprocessing, lemmatization, TF-IDF, and n-gram analysis. Applied ARIMA and SARIMA to forecast monthly customer ratings and developed an MLP neural network to classify ratings from review text. Evaluated model performance and explored challenges such as class imbalance and overfitting.
